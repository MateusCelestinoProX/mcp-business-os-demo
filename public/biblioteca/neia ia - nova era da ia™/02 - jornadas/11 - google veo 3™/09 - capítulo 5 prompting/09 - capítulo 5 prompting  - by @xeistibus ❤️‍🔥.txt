09 - Capítulo 5: Prompting de precisão com JSON

5.1 Introdução: De diretor a arquiteto



Há um método simples para tornar seus prompts muito mais eficazes e instantaneamente mais claros para a IA. É algo que quase dá a sensação de que você está exercendo uma superpotência de prompts. Ele é chamado de JavaScript Object Notation (Notação de Objeto JavaScript), ou JSON, para abreviar.



O JSON é uma maneira simples de armazenar e compartilhar dados para que tanto humanos quanto computadores possam entendê-los.

Você pode pensar nele como uma lista de compras bem organizada e escrita em um formato muito específico - ele tem rótulos (chaves) e valores (as informações reais), e está sempre organizado de uma forma que os computadores podem ler facilmente.

Por exemplo:

{
  "name": "Alex",
  "age": 25,
  "isStudent": true
}



No exemplo acima, vemos:





"name" é o rótulo e "Alex" é o valor.



"age" é o rótulo, e 25 é o valor.



"isStudent" é o rótulo, e true significa sim.



Ela é usada em quase todos os lugares - sites, aplicativos e APIs - para enviar e receber informações em um formato limpo e previsível.

Enquanto a linguagem natural é como falar com um diretor, o JSON é como entregar a ele um projeto arquitetônico detalhado. Na solicitação de imagens e vídeos, essa estrutura é eficaz porque organiza cada elemento da sua solicitação em seções claras e rotuladas que a IA pode interpretar sem adivinhação.

A capacidade de reutilização do JSON o torna uma ferramenta poderosa para a geração de imagens e vídeos, pois permite que você salve uma solicitação perfeitamente estruturada que pode ser usada várias vezes sem perder a clareza ou os detalhes.

Depois de definir elementos como estilo, tema, cenário e movimento da câmera, é possível ajustar rapidamente apenas o que for necessário e manter o restante intacto, garantindo resultados consistentes em várias gerações. Isso não apenas acelera o processo criativo, mas também facilita a manutenção da continuidade em projetos com várias cenas, proporcionando sempre um controle preciso sobre o resultado final.



Neste capítulo, você aprenderá sobre o prompting JSON e algumas maneiras simples de usar essa técnica sem precisar formatá-la manualmente.







5.2 A anatomia de um prompt JSON

Pares de chave-valor

Em sua essência, o JSON funciona por meio de pares - uma chave (o rótulo) e um valor (a informação). A chave informa à IA que tipo de informação ela está vendo, enquanto o valor fornece os detalhes reais. Essa estrutura clara garante que a IA saiba exatamente como interpretar cada parte de seu prompt sem confusão.

Objetos principais

Esses são os principais blocos de construção dos prompts JSON do Veo 3. Cada objeto tem uma função específica na formação da imagem ou do vídeo gerado:





description (descrição) — A narrativa principal e vívida da cena. É aqui que a transformação explosiva, a montagem de elementos e o momento cinematográfico geral são descritos em detalhes.







style (estilo) — Descreve o tom visual e o estilo de renderização, por exemplo: "cinematic, photorealistic", "gritty", "magical", "futuristic". Indica ao Veo 3 a aparência e a sensação desejadas.







camera (câmera) — Especifica movimentos, ângulos e transições da câmera, por exemplo: dolly, crane, orbit, fixed, handheld. Adiciona dinamismo à cena.







lighting (iluminação) — Define a configuração de luz e quaisquer mudanças durante a sequência, por exemplo: golden hour glow, neon city lights, dramatic spotlights.







environment (ambiente) — O cenário físico ou pano de fundo, por exemplo: "futuristic industrial corridor", "sunlit café".







elements (elementos) — Lista dos componentes visuais da cena: adereços, personagens, efeitos, detalhes do ambiente — tudo o que o Veo 3 deve renderizar.







motion (movimento) — A coreografia da ação: como os elementos se movem, se montam, se transformam ou interagem dinamicamente na sequência.







ending (final) — A composição final, descrevendo como a tomada termina.







text (texto) — Qualquer sobreposição de texto para o vídeo, por exemplo: slogans, ou "none" quando não houver.







keywords (palavras-chave) — Lista de tags relevantes para reforçar o direcionamento do prompt, geralmente incluindo proporção, estilo, assunto e efeitos especiais.





Há outros modelos de prompt JSON com diferentes pares de chaves; no entanto, este é o que recomendamos para obter o máximo de clareza, flexibilidade e consistência em projetos complexos de geração de imagens e vídeos.



Aqui está um modelo JSON que você pode usar:

{
  "description": "[Detailed scene description with explosion/transformation and assembly of multiple elements]",
  "style": "[Visual style — always cinematic/photorealistic, can include tone like 'gritty', 'magical', 'futuristic']",
  "camera": "[Camera movement description — dolly, crane, orbit, fixed, handheld, etc.]",
  "lighting": "[Lighting setup and transitions — e.g., golden hour, neon glow, dramatic spotlight]",
  "environment": "[Setting description — interior/exterior, specific location, how it transforms]",
  "elements": [
    "[List each important visual element — props, characters, effects, background features]"
  ],
  "motion": "[Describe how elements move, assemble, explode, transform — choreography of action]",
  "ending": "[Final composed scene — how the video ends visually]",
  "text": "[Text overlay or 'none']",
  "keywords": [
    "[Relevant keywords — aspect ratio, subject tags, special effects, style descriptors]"
  ]
}

A linguagem natural é preferível quando você deseja transmitir rapidamente uma ideia, definir um tom ou experimentar conceitos criativos sem gastar tempo estruturando cada detalhe. Conhecer tanto o JSON quanto o prompt de linguagem natural lhe dá flexibilidade. Você pode escolher o JSON para obter precisão técnica e consistência, e a linguagem natural para obter velocidade e fluxo criativo, permitindo que você se adapte às necessidades de qualquer projeto ou fluxo de trabalho.

Limitações e críticas

Embora o prompt JSON seja poderoso, os críticos observam que, para tarefas criativas, como escrever histórias ou gerar conteúdo com nuances, a estrutura rígida do JSON pode restringir o desempenho do modelo, pois transfere a IA para um modo técnico que prioriza o formato em detrimento da criatividade. Além disso, o JSON pode introduzir ineficiência de tokens devido à sua sintaxe (por exemplo, colchetes e aspas), o que pode aumentar os custos em sistemas baseados em tokens. Alternativas como Markdown ou XML podem, às vezes, oferecer uma estrutura semelhante com menos sobrecarga.



Tente criar seus próprios prompts JSON e experimente diferentes combinações de valores-chave para ver como cada alteração afeta o resultado final. Essa abordagem prática não só aprofunda sua compreensão de como a IA interpreta as instruções estruturadas, mas também o ajuda a descobrir possibilidades criativas exclusivas que podem ser mais difíceis de alcançar apenas com a linguagem natural.
